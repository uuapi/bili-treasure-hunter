# 号海捞珍 · 安卓版使用说明

## 一、安装 APK（一次性）

1. 把 `dist/号海捞珍.apk` 传到手机（微信/QQ 文件传输助手、数据线、网盘均可）
2. 手机上点击 APK → 系统提示"未知来源" → 允许本次安装
3. 安装完成，桌面出现「号海捞珍」图标（2233 图标）

## 二、开始寻号

1. 打开 APP → 底部切到「⚙️ 设置」页：
   - 扫描区间（从/到）、指定尾号（如 0901）
   - 靓号类型勾选（顺子/豹子/回文/交替/尾4/尾3）、连号位数（5=标准，4=小靓号）
   - 数字偏好：不带4 / 不带7 / 不含0 / 额外排除 / 必含数字
   - 并发数建议 2~4（手机网络下 8 容易触发风控）
   - 点「💾 保存设置」
2. 切到「🚀 寻号」页 → 点「🚀 开始寻号」
3. **保持 APP 在前台**（屏幕常亮已自动开启），进度条/命中实时刷新
4. 中途可随时「⏹ 停止」，已扫进度保存在本机，下次接着扫

## 三、战果与导出

- 「📦 战果」页：极品神号 / 神号 / 注册机号 统计与清单
- 「⬇ 导出 CSV」：保存到手机 `下载/号海捞珍/` 目录（文件管理器可见）

## 四、注意事项

- **风控**：手机网络（尤其流量）比宽带更容易触发 -352/-412；频繁拦截时切 Wi-Fi 或降低并发、拉长间隔
- **屏幕**：长扫描请插电 + 保持前台；切后台/锁屏过久系统会限制网络
- **清空记录**：战果页"清空"只清本机数据缓存，不影响断点文件
- 数据（断点+命中）存在 APP 私有目录，卸载 APP 即清空

## 五、重新构建 APK（改完代码后）

电脑上（本仓库环境）执行：

```bash
cd android && bash build_apk.sh
```

产物：`android/dist/号海捞珍.apk`。签名密钥 `android/sign.keystore`
（密码 haohai123）**务必保留**，否则后续版本无法覆盖安装。
